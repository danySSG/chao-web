# Chào! — веб-прототип

Проверка гипотезы: может ли живой голосовой перевод (Gemini Live API)
работать в браузере на iPhone так же, как в нативном приложении.

Открыть: https://danyssg.github.io/chao-web/

Что проверяем:
- доступ к микрофону в PWA, добавленной на домашний экран;
- стриминг PCM 16 кГц в Gemini Live API по WebSocket напрямую из браузера;
- воспроизведение ответа модели (PCM 24 кГц) через Web Audio API;
- эхоподавление: не переводит ли приложение собственный голос.

Ключ Gemini вводится пользователем и хранится только в localStorage браузера.
