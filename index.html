Chào!

Переводчик для жизни во Вьетнаме.
Понимает речь и читает надписи.

  • Говорите по-русски — телефон скажет по-вьетнамски
  • Сфотографируйте меню — переведёт каждое блюдо
  • Полсотни готовых фраз работают без интернета

Нужен бесплатный ключ Google

Приложение переводит через Gemini — сервис Google. Чтобы он работал у вас, нужен личный ключ доступа.

Только вашхранится на телефоне

Аккаунт Google — это почта на @gmail.com. Она есть почти у всех.

Получите ключ

  1. Нажмите кнопку ниже — откроется сайт Google.
  2. Войдите со своим аккаунтом Google, если попросит.
  3. Нажмите синюю кнопку «Create API key».
  4. Если спросит про проект — нажмите «Create project», название любое.
  5. Появится длинная строка — это ключ. Нажмите на значок копирования рядом с ней.
  6. Вернитесь сюда (стрелка «назад» слева вверху или переключение приложений).
Открыть сайт Google

Вставьте ключ

Нажмите на поле и выберите «Вставить». Ключ — это длинная строка из букв и цифр.

Ключ сохранится только на этом устройстве.

Последний шаг

Добавьте Chào! на домашний экран — будет открываться как обычное приложение, во весь экран.
